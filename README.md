# danwave.github.io

Sitio de GitHub Pages de Danwave: https://danwave.github.io/

- `index.html`: portada.
- `wingover/`: el juego Wingover. **No se edita a mano**: lo publica la Action `Deploy to GitHub
  Pages` del repo privado `Danwave/Wingover` en cada push a `main`.
- `roomies/`: el juego Roomies. **No se edita a mano**: lo publica la Action `Deploy to GitHub
  Pages` del repo privado `Danwave/Roomies` en cada push a `main`.
- `turntime/firmware/`: firmware de desarrollo de TurnTime para actualizar por red. **No se edita a
  mano**: lo publica `firmware/turntime/tools/publish-ota.ps1` del repo `Danwave/TurnTime`.
